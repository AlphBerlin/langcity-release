# LangCity 1.0.36 — Release Notes

LangCity 1.0.36 focuses on a smoother, more reliable experience across mobile, web, and desktop.

## Highlights

- Improved startup resilience when Supabase, RevenueCat, or notification services are unavailable.
- Added safer retry and guest/offline fallback behavior so temporary service failures do not prevent the game from opening.
- Improved notification initialization on supported mobile platforms and prevented unsupported platforms from invoking native notification services.
- Improved AI provider configuration for Gemini, DeepSeek, OpenRouter, and OpenAI.
- Added a comprehensive Levels 1–100 curriculum and mission reference.
- Added analytics support across the browser game, landing page, download page, and legal pages.
- Improved public release packaging and macOS signing reliability.

## Technical improvements

- Added startup and Supabase bootstrap resilience coverage.
- Added safer RevenueCat timeouts and error handling for customer info and offerings.
- Added fallback handling for bundled prompts and place registries.
- Updated public web and release assets.
